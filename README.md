# TankPris

TankPris er en mobilvenlig web-app til sammenligning af brændstofpriser i Skandinavien.

## Åbn appen
Når GitHub Pages er aktiveret, er appen tilgængelig på:
https://louisnlindgaard-creator.github.io/tank-pris/

## Indeholder
- 95 / 98 / Diesel / El
- Mobilvenligt layout
- Min placering
- Kort
- Prisrapportering
- PWA-manifest

## Vigtigt om livepriser
Appen må kun vise stationspriser fra kilder, der giver ret til viderevisning. En backend skal bruges til produktionsversionen med station_id, price, currency, fuel_type, source og updated_at.
